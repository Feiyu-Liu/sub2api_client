from the reference checkout's newer working tree. The test stack used its own

The live read-only loop covered capability bootstrap, password login, profile,
Key list, Usage statistics, local-first logout, and session-store cleanup.
Payment was disabled in this deployment, so Billing paths remain proven by the
offline real-Dio transport contract tests rather than a live payment call. No
Key or order was created and no real payment provider was contacted.

## Finding and correction

The first live run correctly failed closed because Usage requested
`/usage/stats`; the server returned its HTTP-200 frontend fallback instead of a
Sub2API envelope. The audit then found that all Usage and Billing Retrofit paths
lacked `/api/v1`, and that order verification serialized `outTradeNo` instead
of the fixed handler's `out_trade_no` field. The endpoints and request field
were corrected, generated code was rebuilt, and real-Dio regression tests were
added for all three Usage routes and eight Billing routes before the successful
live rerun.

## Cleanup

- all three test volumes and the isolated Docker network were removed;
- the disposable credential directory was deleted;
